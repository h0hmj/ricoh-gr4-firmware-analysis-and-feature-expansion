# GR IV / GF-2 单次 C0 查询测试

2026-10-13。针对此前核对的 GR IV `01.11.10.07`。本次热靴命令已在开启的 GF-2 上完整运行，C0 回复 A5，恢复检测返回 0。本文保留初轮操作方案；后续结果见[实机回复](2026-10-13-gr4-hotshoe-live-readings.md)和[A6 实测](2026-10-13-gr4-hotshoe-a6-test-v4.md)。目标是先确认查询可用，再判断关机后的 GF-2 能否响应和完整恢复工作，不需要制作外置硬件。

## 本次准备的卡文件

```text
SD 卡根目录/
  00078560.636
  DEVELOP.MOD
  script/
    startup.ttl
```

两个根目录文件提供原厂工厂菜单入口，`startup.ttl` 是本次单次查询脚本。已有启动脚本必须先备份再替换；不要叠加运行。脚本会在卡根目录生成 `HSC0.TXT`，已有该文件则直接退出。因此每个状态只查询一次，普通重新开机不会再次查询。

脚本先核对工程 shell 基础调用，等待 15 秒，临时暂停普通热靴检测，设置一个零占位字节，发送一次 C0 查询，读取回复，恢复普通检测后写日志。15 秒是脚本等待时间，实际查询相对按下电源键的时间可能更晚。参数使用十进制，不发送 A0/A6 或其他未知命令。

## 启用 Script

如果之前实验的 Script 已经是 Enable，直接进行第一轮。

否则在相机关机时插卡，按住 MENU 再开机，进入原厂工厂菜单，仅将 `FW Setting1 → Script` 设为 `Enable`，然后关机。下次普通开机运行脚本。如果菜单或该项没有出现，先停止并记录页面，不改其他项目。这个入口及菜单位置沿用项目之前的实机流程，不依赖将 Camera Mode 改为 Debug。

## 第一轮：灯开启时的基线

1. 关机时装好 GF-2，插入准备好的卡。
2. 普通开启相机，立即手动打开 GF-2，确认灯正常开启。脚本等待 15 秒，就是给这一步留时间。
3. 保持相机空闲，不半按、不拍照，也不运行其他热靴实验。从开机开始至少等待 30 秒，并等卡读写结束。
4. 正常关机，取卡接电脑，保存并查看卡根目录 `HSC0.TXT`。

成功基线应同时满足：`Disable normal checking`、`Prepare TX[0]`、`Transfer sequence`、`Restore normal checking return` 后的数字均为 0，`RX byte` 后为 165，日志末尾出现 `Single query sequence finished.`。

| 日志结果 | 含义与下一步 |
| --- | --- |
| 完整日志、上述四项为 0、RX 为 165 | 收到 A5，支持正常开启时查询有效；可以继续关闭状态实验 |
| RX 为 201 | 对应 C9，可能是超时占位，也可能是真实数据；不是成功回复的证据 |
| RX 为其他非负值 | 保留原值，先排查格式和通信，不直接解释为开机成功 |
| 某项为 -1 | 命令/调用未成功；结束该轮，保留日志 |
| 某项为 -999 | 那一步没有执行，不能把后续值当作有效结果 |
| Shell precheck failed | 基础 shell 调用失败，没有进入热靴查询 |
| 没有 HSC0.TXT，或只有第一行 | 脚本未执行或未完成，不能据此判断灯不能唤醒 |
| Restore 项不为 0，或日志未完成 | 恢复未确认；移除本次启动脚本、停用 Script，正常重启后再研究 |

## 第二轮：相机关机带着灯关机

仅在第一轮通过后继续。保留 GF-2 安装在机身上，不拔灯、不取灯电池，也不按灯的电源键。

先做对照：保留已有 `HSC0.TXT`，让脚本跳过主动查询。机身带着灯关机后，普通重开相机，观察 30 秒，记录灯是否自行恢复。若对照也恢复，不能把下一轮恢复归因于强制查询。

再做主动查询：正常关闭相机后取卡，把上一轮 `HSC0.TXT` 复制到电脑留存，再删除卡上的该文件。保持灯关闭状态，将卡插回相机，普通开机，**不要手动打开灯**，等待至少 30 秒。记录灯何时亮起、是否恢复就绪指示；正常关机后取卡读取新日志。

如果需要重建相机关机导致的状态，先正常开相机并手动打开灯，再关闭机身，让灯跟着关闭，然后准备下一次查询。不得为了删日志而拔灯或取灯电池，因为那会改变待测状态。

## 第三轮：按键关闭灯

将 GF-2 手动关机，保持安装和电池状态。依照上一节，分别做保留日志、不发送查询的对照，以及保存/删除日志后发送一次查询的实验。这一组与相机联动关机分开记录。

即使关闭状态收到 165/A5，也只证明通信有应答。确认灯恢复指示及充电就绪后，在本轮脚本已完成且恢复检测得到确认的情况下，再检查能否正常闪光，才支持完整恢复工作。

建议每轮记录：灯是正常开启、联动关机还是按键关机；是否主动查询；RX 数值；灯何时恢复；就绪指示；闪光是否正常。先保存每轮日志，再删除卡上的日志安排下一轮。

## 测试结束

把 `FW Setting1 → Script` 设回 Disable，移除本次 `script/startup.ttl`。两个工厂菜单入口文件如仅供本轮使用，也可移除。保留电脑上的旧实验备份和本次日志。
